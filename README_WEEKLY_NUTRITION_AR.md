# FITNESS GYM — خطة الأكل الأسبوعية

هذه إضافة فوق النسخة الحالية ولا تلغي المعرض أو المنتجات أو سجل التمارين.

## التشغيل
1. ارفع ملفات المشروع كما هي.
2. في Supabase → SQL Editor شغّل `supabase-nutrition-weekly.sql` مرة واحدة.
3. افتح لوحة الإدارة → **خطة الأكل الأسبوعية**.
4. اختر اللاعب والأسبوع، وسيتم إنشاء خطة بداية تلقائيًا إذا لم تكن موجودة. عدّل الأيام ثم اضغط حفظ.
5. عند تسجيل اللاعب الدخول، تظهر خطة الأسبوع الحالي فقط. عند بداية أسبوع جديد، النظام ينشئ أسبوعًا جديدًا تلقائيًا من ملف السعرات والهدف.

> الخطة الغذائية عامة للتوجيه، ويمكن للمدرب تعديلها حسب احتياج اللاعب.


### تعدد المستخدمين
تم تأمين إنشاء خطة الأسبوع ضد تعارض الطلبات المتزامنة: إذا دخل أكثر من لاعب في نفس اللحظة عند بداية أسبوع جديد، ينشئ النظام الخطة مرة واحدة فقط ثم يعيدها لباقي الطلبات.
