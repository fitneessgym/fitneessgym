# بوابة اللاعب — FITNESS GYM

## 1) نفّذ SQL مرة واحدة في Supabase
افتح SQL Editor والصق **الجزء الأخير** من `supabase-schema.sql` ابتداءً من `-- Player portal login` ثم Run.

## 2) رفع المشروع
ارفع ملفات المشروع إلى GitHub كما تفعل عادة.

## 3) إنشاء PIN للاعب
من لوحة الإدارة > العملاء، عند إضافة لاعب أدخل PIN من 4 إلى 12 رقمًا. للاعبين الموجودين مسبقًا اضغط زر **PIN** بجانب اللاعب وحدد رمزًا جديدًا.

## 4) جدولة تمرين مستقبلي
من لوحة الإدارة > سجل التمارين، اختر اللاعب واختر تاريخًا مستقبليًا ثم احفظ. سيظهر للاعب تحت **تدريباتي القادمة**.

## 5) دخول اللاعب
من الصفحة الرئيسية > **بوابة اللاعب**، يدخل اللاعب رقم هاتفه + PIN. سيرى فقط سجله هو، وليس سجلات اللاعبين الآخرين.

ملاحظة: نظام البوابة يعتمد على RPC آمن في Supabase ولا يمنح الزائر صلاحية قراءة جداول العملاء أو سجل التمارين مباشرة.


### إصلاح مهم للنسخة الحالية
تم ترتيب تحميل Supabase قبل بوابة اللاعب، كما أصبحت البوابة تحصل على اتصال Supabase وقت تسجيل الدخول بدل الاحتفاظ باتصال غير متاح عند تحميل الصفحة. إذا كان الموقع منشورًا على GitHub Pages، نفّذ تحديثًا قسريًا للصفحة بعد رفع الملفات.
