# خلفية الفيديو الرياضية

تمت إضافة خلفية فيديو رياضية هادئة وبطيئة للصفحة الرئيسية فقط.

- بدون صوت
- تشغيل تلقائي وLoop وplaysinline
- طبقة داكنة فوق الفيديو للحفاظ على وضوح النص
- صورة fallback من معرض الموقع
- إخفاء الفيديو عند تفضيل تقليل الحركة
- لا تغيير في قاعدة البيانات أو ملفات الإدارة واللاعبين

الفيديو الحالي يُحمّل من مصدر Pexels خارجي؛ يمكن لاحقًا تنزيل نسخة محلية مضغوطة إذا أردنا أداءً أسرع.
