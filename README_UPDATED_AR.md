# FITNESS GYM - التحديث الجديد

تم تحديث المشروع ليشمل:

- ربط المنتجات مع Supabase Storage لرفع صور المنتجات بدل تخزين الصور داخل قاعدة البيانات.
- زر شراء المنتج عبر WhatsApp.
- إرسال طلبات التواصل والحجز من الصفحة الرئيسية مباشرة إلى WhatsApp.
- إرسال الفواتير ورسائل العملاء من لوحة الإدارة عبر WhatsApp.
- معرض يدعم الصور وGIF والفيديوهات القصيرة، مع رفعها إلى Storage.
- تدريبات يومية كثيرة قابلة للإضافة والتعديل والحذف، مع صورة الجهاز.
- سجل تمارين خاص بكل لاعب: التمرين، التاريخ، الجولات، التكرارات، الثقل، المدة والملاحظات.
- حاسبة سعرات عامة في الصفحة الرئيسية.
- ملف سعرات لكل لاعب داخل لوحة الإدارة: BMR / TDEE / السعرات المستهدفة / البروتين / الكربوهيدرات / الدهون.
- التحقق من جلسة Supabase وعضوية الحساب في admin_users قبل دخول لوحة الإدارة.
- إصلاح SQL السابق الخاص بـ products.id.

## مهم قبل الاستخدام

1. ارفع الملفات إلى GitHub.
2. في Supabase افتح SQL Editor.
3. شغّل ملف `supabase-schema.sql` المرفق بالكامل مرة واحدة.
4. تأكد أن حساب الإدارة موجود في Authentication وأنه موجود أيضًا في جدول `admin_users`.
5. تأكد أن Storage يحتوي على bucket باسم `site-media` (الـ SQL ينشئه تلقائيًا).
6. افتح الموقع من GitHub Pages، وليس من `localhost`.

إذا ظهرت رسالة RLS عند حفظ منتج أو رفع صورة، فهذا يعني أن جلسة الحساب ليست مرتبطة بعضوية `admin_users` أو أن سياسات `site-media` لم تُطبّق بعد. شغّل SQL المرفق وسجّل الدخول من جديد.
