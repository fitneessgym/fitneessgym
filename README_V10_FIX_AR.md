# إصلاح V10 النهائي لسجل التمارين

هذه النسخة لا ترسل `created_by` ولا `duration` عند حفظ سجل التمرين، لأن قاعدة البيانات الحالية قد لا تحتوي على هذين العمودين.

التمرين يُحفظ باستخدام الأعمدة الأساسية: اللاعب، اسم التمرين، اليوم، التاريخ، الجولات، التكرارات، الوزن والملاحظات.

لا يلزم تشغيل SQL جديد حتى يعمل الحفظ بهذه النسخة. إذا أردت لاحقًا دعم حقل المدة في قاعدة البيانات، يمكن تشغيل ترحيل إضافة العمود `duration` ثم تحديث التطبيق.
