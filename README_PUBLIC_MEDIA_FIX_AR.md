# إصلاح ظهور الصور للجميع

هذه النسخة تجعل صور **التدريبات والمعرض والمنتجات** قابلة للعرض للزوار بدون تسجيل دخول.

## مهم جدًا
بعد رفع الملفات على GitHub، افتح Supabase > SQL Editor وشغّل الملف:

`supabase-public-media-fix.sql`

الملف يجعل Bucket `site-media` عامًا للقراءة فقط، ويُبقي الرفع والتعديل والحذف للإدارة المصادق عليها.

## ما تم إصلاحه
- صور التمارين المحلية داخل `assets/workouts/` تظهر لكل زائر.
- صور المعرض المرفوعة إلى `site-media` تتحول تلقائيًا إلى Public URL عند العرض.
- صور المنتجات المرفوعة إلى `site-media` تتحول تلقائيًا إلى Public URL عند العرض.
- بيانات المنتجات النشطة وبيانات إعدادات الموقع متاحة للزوار عبر RLS.
- لا يتم فتح صلاحية الكتابة العامة.
