# إصلاح ملفات التغذية V14

تم إصلاح عرض ملفات التغذية ليعتمد مباشرة على `customer_nutrition` كمصدر أساسي للسعرات والبروتين والكربوهيدرات والدهون، مع استخدام `customer_nutrition_profiles` لـ BMR وTDEE عند توفرها.

لا تحتاج إلى تشغيل SQL جديد. ارفع `admin.html` و`admin-v14.js` وباقي الملفات كالمعتاد، ثم اعمل Ctrl+Shift+R.
